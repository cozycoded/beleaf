# beLEAF

An emote-focused drawing app. This folder is the whole app, ready to put online for free.
Once it's online, you can install it like a normal app and it works offline.

## Option A: GitHub Pages (free, permanent)
1. Sign in at github.com and create a new repository named `beleaf` (Public).
2. On the repository page, choose **Add file → Upload files** and drag in **everything in this folder** (including the `icons` folder). Commit.
3. Go to **Settings → Pages**. Under "Build and deployment", set **Source: Deploy from a branch**, **Branch: main**, folder **/ (root)**, then Save.
4. After a minute your app is at `https://YOUR-NAME.github.io/beleaf/`.

## Option B: Netlify Drop (quickest)
1. Go to app.netlify.com/drop and sign in (free).
2. Drag this whole folder onto the page. You get a link right away; rename it under Site settings if you like.

## Install it as an app
- **Windows (Chrome/Edge):** open your link, then click the install icon in the address bar (or Edge: ⋯ → Apps → Install beLEAF).
- **Android (Chrome):** open your link, ⋮ → Add to Home screen / Install app.
- **iPhone/iPad (Safari):** Share → Add to Home Screen.

## Updating
Replace the files with a newer build (same names). Open the app once while online and it updates itself next time.

Your drawings and settings are saved on each device. To move work between devices use
**File → Save project file (.beleaf)** and **File → Open project file**, and **Settings → Export all settings**.
